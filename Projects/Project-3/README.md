# Variational Auto-Encoder (VAE) on MNIST using SGVB

A complete PyTorch implementation of a **Variational Auto-Encoder (VAE)** trained on the MNIST dataset using the **Stochastic Gradient Variational Bayes (SGVB)** estimator. This project demonstrates probabilistic generative modeling by learning a continuous latent space from which new handwritten digit images can be generated.

---

## 🚀 Key Features

* **Probabilistic Generative Modeling**:

  * Encoder learns a distribution over latent variables.
  * Decoder reconstructs images from sampled latent representations.
* **SGVB Estimator**:

  * Uses the reparameterization trick for low-variance gradient estimation.
  * Enables efficient end-to-end training via backpropagation.
* **Stable and Interpretable Training**:

  * Optimizes the Evidence Lower Bound (ELBO).
  * Explicit latent space representation with Gaussian prior.
* **End-to-End Image Reconstruction & Generation**:

  * Fully connected architecture optimized for MNIST digits.
  * Supports both reconstruction of input images and generation of novel samples.

---

## 🏗️ Architecture Overview

The model follows the standard **VAE framework**, consisting of an Encoder and a Decoder trained jointly.

### 1. **Encoder**

* Input: Flattened 28×28 grayscale image (784 dimensions).
* Fully connected hidden layer with ReLU activation.
* Outputs:

  * Mean vector (μ)
  * Log-variance vector (log σ²)
* Latent space dimension: 20

### 2. **Decoder**

* Input: Latent vector sampled using the SGVB reparameterization trick.
* Fully connected hidden layer with ReLU activation.
* Output layer with Sigmoid activation producing pixel-wise probabilities.

## 📊 Results & Performance

The VAE was trained for 30 epochs on the MNIST dataset, achieving stable convergence and meaningful latent representations.

| Metric                      | Value                           |
| :-------------------------- | :------------------------------ |
| **Final ELBO Loss**         | Decreases steadily              |
| **Reconstruction Quality**  | Preserves digit structure       |
| **Latent Space Smoothness** | Continuous and well-regularized |
| **Training Stability**      | Highly stable                   |

### Image Generation

New handwritten digits are generated by sampling latent vectors from a standard normal distribution and decoding them into image space. Reconstructions closely resemble original inputs, while generated samples reflect the overall MNIST data distribution.
